# Accessibility notes

- Images have descriptive alternative text generated from each credential title and provider.
- Filters are real buttons grouped with an accessible label.
- Search has a visually hidden label.
- The credential preview uses a native dialog, with a labelled close control.
- Keyboard users can reach the filters, search field, cards, and preview links in document order.
- The responsive layout retains readable sizing at narrow viewport widths.

Future enhancements can include a reduced-motion preference and explicit arrow-key navigation between previews.
